# Вид «Столпов»

Тёмный «Пульт» под телефон: плотные строки, линии вместо отступов, один янтарный акцент. Токены лежат в `src/ui/styles/tokens.css`, сброс и типографика в `base.css`, компоненты в `components.css` и экранных файлах. Цвета берутся из дизайн-системы без изменений; здесь описано, как их применять в телефонной вёрстке.

## Правила

1. Тёмная тема одна. `color-scheme: dark`, `theme_color` и фон `#131519` (`--bg`). Светлой темы нет и не будет.
2. Янтарь (`--amber`, `--amber-l`) значит только выбор и действие: активный чип, главная кнопка, фокус. Больше ни для чего. Одна главная кнопка на экране, закреплена внизу над панелью, в safe-area.
3. Разделение линиями (`--line`, `--line-sub`), а не пустыми отступами и не карточками с тенью. Тень только у того, что висит над сценой: лист, тост.
4. Три голоса. Ярлык: IBM Plex Mono, капс, 11-12px, трекинг `.14em` (`.lbl`). Текст: Golos Text, 15px, крупный 17px, заголовок экрана 20px. Цифра: моно, табличные цифры (`.num`), таймер 56px (`.timer`). Крупные заголовки: Unbounded 24-28px, капс, трекинг `.08em` (`.display`).
5. Цвет столпа живёт в его переменной и красит только шкалу и число этого столпа. Сила `--pillar-strength` (`--cat-2`), зона 2 `--pillar-zone2` (`--cat-5`), интервалы `--pillar-intervals` (`--cat-3`), мобильность `--pillar-mobility` (`--cat-1`), баланс `--pillar-balance` (`--cat-4`). `--cat-6` и `--cat-7` не используются: они близки к янтарю и читались бы как «активно».
6. Зелёный статус (`--green`) только для точек и подтверждений. Шкалы столпов им не красятся, хотя у баланса оттенок близкий: баланс берёт `--cat-4`, статус берёт `--green`, и они не встречаются в одном элементе.
7. Касания от 44px (`--tap`), главные действия 48px (`--tap-main`). Зона нажатия может быть больше видимого элемента.
8. Радиусы 0, 2, 3px (`--r-0`, `--r-1`, `--r-2`). По умолчанию 0; 2-3px у плит, которые висят над сценой (лист, тост).
9. Safe-area только через `max()`: переменные `--safe-top`, `--safe-right`, `--safe-bottom`, `--safe-left`. Корень `#root` уже учитывает их; закреплённые элементы (панель вкладок, панель действий, лист) берут те же переменные сами. Высота экрана `100dvh`, не `100vh`.
10. Нажатие: `:active { transform: scale(.97) }` (в `base.css` для кнопок, ссылок, `role="button"`, `role="tab"` и `.pressable`). Фокус с клавиатуры виден янтарным контуром (`:focus-visible`), без него не обходится ни один интерактивный элемент.
11. Движение уважает `prefers-reduced-motion`: анимации и переходы сводятся к нулю глобально. Смысл не может зависеть от анимации.
12. Поля ввода 16px и выше (`--fs-input`), иначе iOS увеличивает страницу при фокусе.
13. Шрифты свои, из `public/fonts` (woff2, лицензия OFL рядом), `font-display: swap`. Внешних запросов за шрифтами нет, приложение поднимается офлайн.

## Копирайтинг

- Только дефис. Длинного и среднего тире нет нигде: ни в коде, ни в комментариях, ни в документах, ни в текстах интерфейса. Проверяет `test/dashes.test.ts`.
- Кавычки только «ёлочки». Разделитель в строках метаданных « · » (точка посередине с пробелами): «Сила A · 45 мин · 18 подходов».
- Без точек на конце в кнопках, чипах, ярлыках и заголовках. В длинном тексте предложения заканчиваются точкой как обычно.
- Числительные склоняются через `pluralRu` и готовые слова из `src/core/plural.ts`: `${n} ${minutesWord(n)}`. Формы вида «1 минут» недопустимы.
- Вес с запятой через `formatKg` (`62,5 кг`), часы секундомера через `formatClock`, длительности через `formatMinutes`. Даты через `formatDateShort` и `formatDateFull`.
- Ошибка двумя словами и выходом: «Не сохранено» и кнопка «Повторить». Без «Упс», без извинений, без восклицательных знаков.
- Пустое состояние всегда с выходом: что здесь появится и кнопка, которая это создаёт («Пока нет тренировок» и «Начать первую»).
- «Нет данных» пишется курсивом и тусклым цветом (`.nodata`), без заглушек вроде нулей и прочерков в числовой колонке.
- Тон ровный и деловой: без оценок личности, без советов не по теме экрана, без эмодзи.

## Компоненты

Ниже разметка, по которой компоненты собираются в `components.css` и экранных файлах. Имена классов и атрибуты считаются контрактом: экраны ссылаются на них, не на внутреннее устройство.

### Scale (шкала столпа)

Строка недели. Имя столпа ярлыком, число цветом столпа, шкала с отметками минимума и цели, вторичная строка мелко. Цвет столпа приходит через переменную `--c` на самой строке.

```html
<div class="scale" style="--c: var(--pillar-strength)" role="img"
     aria-label="Сила: 32 из 50 подходов, минимум 20">
  <div class="scale-head">
    <span class="lbl">Сила</span>
    <span class="num scale-value">32 из 50 подходов</span>
  </div>
  <div class="scale-track">
    <div class="scale-fill" style="width: 64%"></div>
    <span class="scale-mark scale-mark-min" style="left: 40%"></span>
  </div>
  <div class="scale-sub">2 силовых дня из 3 · не в зачёт: запас больше трёх</div>
</div>
```

Заливка `--c`, дорожка `--line`, отметка минимума яркая линия `--line-hi`. Достигнутая цель добавляет точку `--green` рядом с числом, шкала цвет не меняет. Заливка больше 100% упирается в край.

### Chip (чип)

Выбор одного из нескольких: место, фильтр, оборудование. Минимум 44px по высоте. Активный: янтарная рамка и заливка.

```html
<div class="chips" role="radiogroup" aria-label="Место">
  <button class="chip" role="radio" aria-checked="true">Дом</button>
  <button class="chip" role="radio" aria-checked="false">Зал</button>
</div>
```

Для множественного выбора `role="checkbox"` и `aria-checked`. Состояние читается из `aria-checked`, а не из отдельного класса; стиль активного вешается на `[aria-checked="true"]`.

### Stepper (счётчик вес, повторы, секунды)

Крупные кнопки минус и плюс по бокам поля. Поле числовое (`inputmode="decimal"`), принимает запятую и точку, разбор через `parseDecimal`.

```html
<div class="stepper" role="group" aria-label="Вес, кг">
  <button class="stepper-btn" aria-label="Меньше">-</button>
  <input class="stepper-input num" inputmode="decimal" value="62,5">
  <button class="stepper-btn" aria-label="Больше">+</button>
</div>
```

Кнопки 48px, шаг задаёт экран (2,5 кг для веса, 1 для повторов, 5 для секунд). Поле и кнопки образуют одну линейку с общими границами `--line`.

### RestBar (полоса отдыха)

Закреплена над панелью действий, пока идёт отдых. Слева остаток в `formatClock`, посередине полоса убывающего времени, справа действия.

```html
<div class="rest-bar" role="timer" aria-live="off">
  <span class="lbl">Отдых</span>
  <span class="num rest-left">1:12</span>
  <div class="rest-track"><div class="rest-fill" style="width: 80%"></div></div>
  <button class="rest-btn" aria-label="Добавить 15 секунд">+15</button>
  <button class="rest-btn" aria-label="Пропустить отдых">Пропустить</button>
</div>
```

Ширина полосы вычисляется из времени окончания (`endsAt`), а не накапливается тиками, поэтому после сворачивания приложения полоса верна. Звук и вибрация сообщают об окончании, экран без движения тоже читается: остаток цифрами.

### Sheet (нижний лист)

Модальная панель снизу: выбор упражнения, ввод подхода, подтверждение. Подложка `--scrim`, радиус верхних углов `--r-2`, граница `--amber-line-hi`.

```html
<div class="sheet-scrim" data-close>
  <section class="sheet" role="dialog" aria-modal="true" aria-labelledby="sheet-title">
    <header class="sheet-head">
      <h2 id="sheet-title" class="title">Подход</h2>
      <button class="sheet-close" aria-label="Закрыть">Закрыть</button>
    </header>
    <div class="sheet-body"><!-- содержимое --></div>
    <footer class="sheet-foot">
      <button class="btn btn-main">Записать</button>
    </footer>
  </section>
</div>
```

Лист закрывается по подложке, по кнопке и по Escape; фокус при открытии уходит внутрь и возвращается на кнопку, открывшую лист. Нижний отступ листа `--safe-bottom`. Главная кнопка листа одна и стоит в `sheet-foot`.

## Чеклист проверки экрана

1. Одна главная кнопка (янтарная, 48px), закреплена внизу в safe-area. Остальные действия вторичные.
2. Янтарь встречается только на выборе, действии и фокусе. Цвет столпа только на шкале и числе своего столпа.
3. Все касаемые элементы не меньше 44px, главные 48px, между соседними есть зазор или линия.
4. Ярлыки моно капсом, текст Golos, цифры моно с табличными цифрами. Нет четвёртого шрифта.
5. Все числительные со словом идут через `pluralRu` или готовые слова. Вес через `formatKg`, время через `formatClock` и `formatMinutes`.
6. В текстах нет тире (только дефис), кавычки «ёлочки», разделитель « · », нет эмодзи, нет точек в кнопках.
7. Есть пустое состояние с выходом, есть состояние ошибки двумя словами, «нет данных» курсивом тусклым.
8. Проходит клавиатурой и читалкой: видимый фокус, у иконок и кнопок без текста есть `aria-label`, у шкал `aria-label` с числами.
9. Экран не ломается при шрифте системного размера крупнее обычного и на ширине 320px, нет горизонтальной прокрутки.
10. Закреплённые элементы не перекрывают содержимое: нижний отступ прокручиваемой области равен высоте панели плюс `--safe-bottom`.
11. Включён `prefers-reduced-motion`: ничего не теряется, анимация не несёт смысла.
12. Нет `100vh`, нет фиксированных пикселей для safe-area, нет цветов вне токенов.
13. `npm test` зелёный (включая тест на тире), `npm run build` проходит.

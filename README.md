# Столпы

Приложение для записи тренировок по пяти столпам: сила, зона 2, интервалы, мобильность, баланс. Работает как PWA на телефоне, без сервера и без аккаунта.

Открыть: https://s4s4s4s.github.io/stolpy/

## Команды

```
npm ci                          установка по lock-файлу
npm run dev                     сервер разработки
npm run build                   проверка типов и сборка в dist
npm run preview                 просмотр собранной версии
npm test                        все тесты (test/*.test.ts)
npm run test:one -- <имя>       тесты, в имени файла которых есть подстрока
npm run icons                   иконки и сплэши iOS в public/
npm run fonts                   шрифты в public/fonts и src/ui/styles/fonts.css
npm run shots                   снимки экранов (headless Chrome)
npm run demo                    демо-состояние для снимков
```

## Хук коммитов

Сообщения коммитов проверяются на длинное и среднее тире. Включить один раз после клонирования:

```
git config core.hooksPath .githooks
```

Те же символы в файлах репозитория ловит тест `test/dashes.test.ts`.

## Данные

Все данные хранятся только на телефоне, в IndexedDB браузера. На сервер ничего не отправляется. Резервная копия - JSON-файл, который создаётся и восстанавливается в настройках приложения.
